# Performance

See [performance evidence](PERFORMANCE_BENCHMARKS.md) for reproducible results,
workload limits, and instructions for the signed VES load harness. See
[service level objectives](SLO.md) for targets. The targets are not measured
capacity or a service level agreement.

Earlier versions of this page contained throughput, latency, cache-hit,
scaling, and storage estimates without a traceable run, commit, or dataset.
Those estimates have been withdrawn. Use the CI artifacts or a documented
deployment-specific measurement when sizing the sequencer.
